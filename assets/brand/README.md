# MindIE Diagnostics (`mindie-diagnostics`) brand assets

The guardian-shield Agent mark (rounded shield with Agent eyes, four-point spark, and lower ECG triage pulse line) identifies `mindie-diagnostics` within the MindIE Agent brand family.

- `diagnostics-logo-source.png`: 1254 × 1254 master transparent PNG.
- `diagnostics-logo.png`: 512 × 512 transparent PNG for repository READMEs and avatars.
- `diagnostics-icon.png`: 128 × 128 compact transparent PNG for UI icons.
- `PROMPT.md`: generation prompt and visual family reference.

Brand accent: `#7045F5` (aligned to the parent [`mindie-agent`](https://github.com/mindie-agent/mindie-agent/tree/main/assets/brand) tile and alpha mask). The same high-contrast mark works on light and dark backgrounds. Preserve its aspect ratio and transparent outer margin.
