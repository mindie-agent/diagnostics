# mindie-diagnostics 0.5.9：保留子进程异常证据

[English](diagnostics-0.5.9.en.md)

发布已合入的 #37，为独立插件脚本及子进程传输提供共享的有界异常证据接口。保留自有代码的模块、函数、行号、异常类链、重新计算的栈指纹与类型化 errno；父级包装异常不再覆盖更具体的子进程证据。

不序列化异常消息、本地路径、局部变量、源代码、标准输出、标准错误或任意异常属性。传输数据重新校验；现有上报授权、未授权历史不回填及 incident 去重规则不变。

本版本改善后续故障的可诊断性，不代表已经定位或修复 mindie-agent#324 的历史触发原因。现有安装仍需完成组件发现、准备与运行时切换，已加载的宿主进程另需自然重载。

完整组件测试、精确 Tag benchmark、发行包与 SHA256SUMS 由正式发布工作流核验并附于 Release；不声称原始用户故障复现或 NPU 验收。
